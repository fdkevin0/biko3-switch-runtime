# Switch 运行与安装

Switch 后端使用 libnx 输入/音频和锁定 Mesa NVK。默认日文资源，可选汉化与去码。自建程序和数据包见[构建与打包](build.md#switch)，操作见[按键说明](controls.md)。

## NRO

以完整内存的应用模式运行 `biko3-runtime.nro`。常用目录：

```text
sdmc:/switch/biko3/
├── biko3-runtime.nro
├── game/
│   ├── Data/
│   └── patch.pp
├── save/
├── captures/
└── album/
```

默认进入原版标题。NRO 的可写输出留在 SD 上；正式构建不创建或轮换 `.log` 文件。出错时屏幕仍显示原因，可按 B 返回。历史 SD 包不会随源码或 GitHub 推送自动更新。

NRO 和 BKPT2 外挂需配套更新。原 Data 无须因一次程序修复重复复制；重新打包完整目录时才使用[SD 工具](build.md#sd-目录)。

## NSP

本地交付采用本体加 BKTR 更新：

| 包 | TitleID | 内容 |
| --- | --- | --- |
| 原版直装本体 | `01094F68D7330000` | 原版日文 Data 和程序；历史显示版本 1.0.78 |
| 汉化与去码更新 | `01094F68D7330800` | 关联本体的 BKTR Patch，程序与合并外挂；已记录显示版本 1.0.79cn |

先安装本体，再安装匹配的更新。安装后从 HOME 进入，名称「尾行3」、作者 `ILLUSION`。本体不依赖 NRO 的 SD Data 目录。

本体及更新的实际文件摘要、内容版本和检测范围分别见[本体记录](../reports/nsp-1.0.78.md)、[1.0.79cn 更新记录](../reports/nsp-update-1.0.79.md)。显示版本、内容版本和程序构建摘要是不同字段，核对时不能混用。此前的 `...3000` / `...3800` 包属于更换 TitleID 前的历史包。

### 存档与照片

NSP 的进度、配置和游戏内照片写入当前所选用户的 HOS SaveData，所属 ID 为本体 `01094F68D7330000`。当前分配为 2 GiB 存档和 64 MiB journal；写入/删除后显式提交。照片由游戏相册查看。

旧 NRO 的 SD 存档、旧 TitleID 的 HOS 存档不会自动迁入当前 NSP。不要通过更名文件或混用包来假定已经迁移，存储格式与接入证据见[本体与存储报告](../reports/nsp-1.0.78.md)。

### 其他外挂方式

也可在用户自行配置的 Atmosphere LayeredFS 路径放置 `patch.pp`：

```text
atmosphere/contents/01094F68D7330000/romfs/patch.pp
```

此方式依赖已有 LayeredFS 配置；本项目未把它计为新增实机验证。安装内置汉化的更新包时无需再复制一份 NRO 外挂，补丁说明见[汉化与去码](patches.md)。

## 已记录的验证范围

2026-10-02 的正式 NRO 与更新包已交付。相关主机回归和 NVK 交叉构建完成；最新内容版本 196610 的更新仅做打包器生成检查，没有追加独立合并检测或安装运行。此前内容版本的独立验证只证明其对应旧产物。

后续安装、性能和持续运行由用户自行验证，按实际反馈维护；当前源码上的 macOS 修复不表示已重建 Switch 交付包。最新源码与各平台验证范围见[状态页](roadmap.md)。
