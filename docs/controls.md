# 操作说明

各平台使用同一套游戏操作，桌面通过 SDL3 将键盘、鼠标、触屏和标准手柄映射为游戏输入。macOS 的窗口与菜单额外按键见 [macOS 说明](macos-native.md#菜单栏)。

## 基本按键

| Switch / 手柄 | 桌面键盘 | 作用 |
| --- | --- | --- |
| A / 下侧按键 | Enter / Space | 确认、交互、对白推进 |
| B / 右侧按键 | Esc / Backspace | 菜单返回、确认框取消；游戏姿态切换 |
| X / 左侧按键 | X | 游戏镜头切换 |
| Y / 上侧按键 | C | 拍照 |
| 左摇杆 | WASD | 游戏移动；支持光标的菜单中移动光标 |
| 十字键 | 方向键 | 菜单逐项选择 |
| 右摇杆 | — | 游戏视角 |
| L / LB | Q | 结局、特殊剧情镜头旋转修饰键 |
| R / RB | E | 结局、特殊剧情镜头远近/高度修饰键；剧情文字中按住快进 |
| ZL / LT | Shift | 慢走；菜单光标减速 |
| + / Start | Tab | 游戏暂停菜单；选人确认；音量页恢复默认 MAX |
| − / Select | F1 | 原版 FPS 开关，默认关闭 |

结局与特殊剧情中，L + 右摇杆旋转镜头；R + 右摇杆右推拉近、左推拉远、上推升高、下推降低。手动镜头保持已有 6 倍适配，自动轨道不加速。特定人物手动动作阶段的左摇杆为 2 倍，其余动作原速，具体阶段见[侧栏修复记录](../reports/ending-sidebar.md)。

## 菜单与触屏

主菜单、选人、存读档和 SYSTEM 显示游戏光标。左摇杆自由移动、ZL 减速、十字键逐项选择、A 确认。桌面鼠标/触屏可定位光标，点击行为按场景输入适配。

- 选人、存读档、鉴赏和相册目录按 B 返回。
- SYSTEM 主界面按 B 恢复游戏；确认框中先取消当前层。
- 音量页按 B 保存返回，+ 恢复语音、音乐和音效三项 MAX（0 dB）。
- 剧情文字界面按住 R 连续强制快进，松开停止；A 为单次推进。
- 结局拖动目标时按住 A 滑动；音量条支持触屏直接点击和拖动。

左侧操作说明保持金色，在汉化启用时显示中文，默认日文；说明不会写进相册照片。macOS 可用 F2 或菜单开关帮助。菜单快捷键证据见[报告](../reports/menu-shortcuts.md)。
